# About `rust/z2edit/src/gui`

- error_dialog.rs: ImGUI error dialog.
- file_dialog.rs: Usability wrapper around "NativeFileDialog".
- mod.rs: The root of the module.
- preferences.rs: A preferences dialog.
- project.rs: The main GUI widget for an entire romhack project.
- util.rs: Various utility helpers.
- visibility.rs: A helper for window visibility.
- widgets.rs: Helpers for building GUI widgets.
- wizard.rs: A new project wizard dialog.
