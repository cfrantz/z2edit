# About the `rust` subdirectory

This subdirectory contains the rust-language code for z2edit.  It is divided into several crates.

- imgui-rs: A git submodule referencing the `imgui-rs` crate.
- nes: Nintendo Entertainment System emulator and NES-file utilities.
- pybind11: A git submodule referencing the `pybind11` library.
- python_gui: A crate for building an ImGUI application in rust and python.
- z2edit: The z2edit editor for "Zelda II: The Adventure of Link" (aka Zelda 2)
