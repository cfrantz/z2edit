# About `rust/nes/gui`

This subdirectory contains GUIs for many NES components.
- apu.rs: A debug gui for the APU.
- controller.rs: A debug gui for the NES controllers.
- emulator.rs: A GUI for the whole emulator.
- key.rs: Keybindings used by the GUI.
- memory.rs: A debug gui for NES RAM regions.  Displays a hexdump.
- mod.rs: The module root.
- ppu.rs: A debug gui for the NES PPU.  Displays a colored hexdump, scroll areas, active sprites, register contents and a rendering of the CHR memory space currently mapped.
